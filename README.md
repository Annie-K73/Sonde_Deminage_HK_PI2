# Sonde_Deminage_H-K
# IHM – Sonde de déminage 2.0  Ce dépôt regroupe le développement de l'IHM du projet. Elle permet à l’opérateur de suivre les mesures réalisées par la sonde, de visualiser les données des capteurs et de consulter les résultats de détection.  Le développement suit une approche progressive et itérative.
